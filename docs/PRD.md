# 모임 매니저 MVP PRD

## 🎯 핵심 정보

**목적**: 수영·헬스·러닝 등 정기 모임 주최자가 카카오톡+엑셀+수기 정산으로 처리하던 공지·참여자·카풀·정산 업무를 한 곳에서 처리하게 한다.
**사용자**: 정기 모임(동호회)을 운영하는 주최자와, 초대받아 참여하는 멤버.

## 🚶 사용자 여정

```
1. 로그인 페이지 / 회원가입 페이지
   ↓ 로그인 성공

2. 홈 페이지 (내 모임 목록)
   ↓ 선택

   [속한 모임 있음] → 모임 상세 페이지
   [속한 모임 없음] → "모임 만들기" → 모임 생성 페이지 → 모임 상세 페이지
   ↓

3. 모임 상세 페이지 (공지 · 회차 목록 확인, 초대 링크 발급)
   ↓ 회차 선택

4. 회차 상세 페이지 (공지 확인, RSVP 응답)
   ↓ RSVP

   [참석] → 카풀 페이지에서 카풀 등록(선택)
   [불참/미정] → 홈 페이지로 복귀
   ↓ (회차 종료 후 주최자가 비용 등록)

5. 정산 페이지 → 본인 분담액 확인 → 완납 체크 → 완료
```

```
[별도 흐름 — 초대받은 신규 사용자]

1. 초대 링크 클릭
   ↓
   [비로그인] → 로그인 페이지 / 회원가입 페이지 → 로그인 성공
   ↓
2. 초대 합류 페이지 (모임 합류 처리)
   ↓ 합류 완료
3. 모임 상세 페이지
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID         | 기능명                      | 설명                                                                                                     | MVP 필수 이유                                                 | 관련 페이지                                          |
| ---------- | --------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------- |
| **[F001]** | 모임 생성 및 정기 일정 관리 | 모임 기본정보(이름/카테고리/정원) 입력, 반복 규칙 설정 시 회차 자동 생성, 개별 회차 수정(휴강/장소 변경) | 정기 모임 운영의 기본 단위가 없으면 다른 기능이 성립하지 않음 | 모임 생성 페이지, 모임 상세 페이지, 회차 상세 페이지 |
| **[F002]** | 초대 및 합류                | 모임별 초대 링크/코드 발급, 링크 클릭 시 합류 처리                                                       | 단톡방 초대를 대체하는 최소 진입 수단                         | 모임 상세 페이지, 초대 합류 페이지                   |
| **[F003]** | 공지 작성 및 조회           | 모임/회차 단위 공지 작성, 상단 고정, 최신순 목록 노출                                                    | 단톡방에 묻히는 공지 문제를 해결하는 핵심 가치                | 모임 상세 페이지, 회차 상세 페이지                   |
| **[F004]** | RSVP 및 대기열              | 참석/불참/미정 응답, 정원 초과 시 자동 대기열 등록, 취소 발생 시 대기 1순위 자동 승격                    | 참여자 수기 취합을 대체하는 핵심 가치                         | 회차 상세 페이지                                     |
| **[F005]** | 참여자 명단 관리            | 확정/대기/불참 현황 조회, 비회원 게스트 동반 기록                                                        | 주최자가 회차별 참석 규모를 한눈에 파악해야 카풀·정산이 가능  | 참여자 관리 페이지                                   |
| **[F006]** | 카풀 등록 및 매칭           | 운전 가능(출발지/좌석수) 또는 탑승 필요(희망 출발지) 등록, 등록 목록 조회, 좌석 마감 시 모집완료 표시    | 수작업 매칭의 누락·중복을 줄이는 핵심 가치                    | 카풀 페이지                                          |
| **[F007]** | 비용 항목 등록 및 N빵 계산  | 회차/모임 단위 비용 항목 등록, 참석 확정 인원 기준 자동 분배 계산, 금액 수동 조정                        | 수기 정산 계산을 대체하는 핵심 가치                           | 정산 페이지                                          |
| **[F008]** | 정산 상태 관리              | 참여자 본인이 송금 완료 체크, 주최자가 최종 확인 처리                                                    | 미납자 추적이라는 주최자의 핵심 페인포인트 해결               | 정산 페이지                                          |

- 모바일 앱(iOS/Android), 푸시 알림
- 프로필 상세 관리(아바타, 자기소개 등), 설정(테마/언어)
- 다국어 지원
